"@prefactor/pi": minor
---

Add `@prefactor/pi`, a pi extension that records each pi session in Prefactor as an agent instance, with spans for agent runs, LLM responses (including cache token counts and cost) and tool calls. Install it with `pi install npm:@prefactor/pi` and supply credentials through extension options, the `PREFACTOR_*` environment variables or `~/.pi/agent/prefactor.json`.
